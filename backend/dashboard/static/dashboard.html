Making a code…

  1. Connect your phone to the same Wi-Fi as this laptop.
  2. Scan the code with your phone's camera and open the link.
  3. Your phone warns that the connection isn't private. That's expected: this laptop made its own certificate. Tap Advanced → Proceed (Android) or Show Details → visit this website (iPhone). You only do this once.
  4. Tap Link this phone, then record and press Send to my dashboard.

The phone opens . Each code works once, for 5 minutes.
